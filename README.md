# Steb

Steb is an unofficial [Standard Ebooks](https://standardebooks.org) frontend on a jailbroken Kindle. 

## Build

```
git clone https://github.com/huangziwei/steb && cd steb/
./build.sh
```

## Install

| from | to | notes |
|:--|:--|:-- |
| `device/extensions/steb/` | `/mnt/us/extensions/steb/` | or anywhere you store your extensions |
| `device/documents/Steb.sh` | `/mnt/us/documents/Steb.sh` | or anywhere you store your scriptlets |
